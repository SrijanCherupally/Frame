# Download Frame for Windows

**[Download ZIP](https://github.com/SrijanCherupally/Frame/raw/refs/heads/main/downloads/Frame-Windows-x64.zip)** — recommended.

Extract All, then double-click **Start-Frame.cmd**. The first launch downloads and verifies the required FFmpeg media tools into the app folder. No compiler, npm, administrator setup, or PATH changes are needed. Internet access is required on the first launch.

**[Frame.exe only](https://github.com/SrijanCherupally/Frame/raw/refs/heads/main/downloads/Frame.exe)** — for an existing FFmpeg installation.

[SHA-256 checksums](SHA256SUMS.txt). Unsigned Windows x64 build, cross-compiled on Linux; Windows runtime and downloader testing are still outstanding.
