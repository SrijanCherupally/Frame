# Download Frame for Windows

**[Download the complete offline ZIP](https://github.com/SrijanCherupally/Frame/raw/refs/heads/main/downloads/Frame-Windows-x64.zip)**

Choose **Extract All**, then double-click **Frame.exe**. FFmpeg, FFprobe and FFplay are included; no separate download, setup script, compiler, npm, administrator setup, or PATH changes are needed. Keep all four executables together.

**Preview fix:** use this complete updated ZIP to replace the older media tools that lacked PNG support. Replacing only Frame.exe does not repair that codec omission. Preview errors now have Details and Retry controls.

Use **Theme** to choose Midnight, Graphite, Amethyst, Forest or Dawn (light), and the Edit / Color / Audio / Motion workspaces for focused editing controls.

**Motion Studio** adds editable timing curves, Bézier paths, reusable animation and smooth reveals. Graphics now include CSV data charts and seven explanation scenes. See the [reference breakdown and production guide](../docs/animation-guide.md).

**VFX Studio** adds point tracking, editable vectors/stroke drawing/morphing, 3D scenes/OBJ meshes, and animation shutter blur. [Workflow guide](../docs/vfx-guide.md). Examples are included in Templates and Templates/VFX.

**GPU acceleration:** NVIDIA NVENC export and automatic DX12/Vulkan 3D rendering are included. Open Settings or Export → Hardware acceleration → Check GPU & encoder. Use this full ZIP to upgrade the media tools too. [RTX laptop setup and limits](../docs/gpu-guide.md).

The standalone `Frame.exe` file in this folder is only the application component; use the full ZIP for the included media tools, templates, licenses and corresponding source. [Checksums](SHA256SUMS.txt).

Unsigned Windows x64 build, cross-compiled on Linux. Genuine Windows runtime testing remains outstanding.
