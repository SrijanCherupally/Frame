# Example chart data

`illustrative-flight-profile.csv` contains invented time (seconds) and altitude (meters) values for trying **Graphics → Data curve → Import time / value CSV**. It is an illustration, not measured flight telemetry or a physical simulation.

Import your own measurements for factual videos. Use two numeric columns, strictly increasing time/X values, and no more than 2,048 points. Points are embedded in the saved `.frame` project.
