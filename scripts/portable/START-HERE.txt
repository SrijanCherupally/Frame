FRAME FOR WINDOWS — OFFLINE QUICK START

1. Download the full Frame ZIP and choose Extract All.
2. Double-click Frame.exe in the extracted folder.

FFmpeg, FFprobe and FFplay are included. No internet connection, compiler,
npm, administrator setup, or separate media-tool installation is needed.
Keep all four .exe files together. Start-Frame.cmd is an optional shortcut.
Do not launch the app from inside the ZIP.

Choose Theme in the top bar for Midnight, Graphite, Amethyst, Forest or
Dawn (light). Your choice is saved on this device and never changes video
colors. Use Edit, Color, Audio and Motion workspaces for focused controls.

Choose Motion > Open Motion Studio for easing curves, curved paths,
reusable animations and smooth reveals. Graphics > Data curve can import
a time/value CSV. Mask > Text places footage inside large lettering.
See docs/animation-guide.md for the timestamped reference breakdown.

Graphics > Vector Studio / 3D Studio opens editable paths and 3D scenes.
Motion > Tracking / Motion blur opens tracking and animation shutter blur.
Try the VFX example projects in Templates and Templates/VFX.
See docs/vfx-guide.md for the supported workflows and limits.

Settings / Export > Hardware acceleration offers NVIDIA NVENC encoding
and automatic GPU 3D rendering. Click Check GPU & encoder to test them.
Install a current NVIDIA driver for RTX laptops; no CUDA toolkit needed.
Use the full updated ZIP when upgrading to NVENC support. CPU fallback is
available. See docs/gpu-guide.md for supported stages and troubleshooting.

Open a .frame project from Templates to try explanation graphics.
Use the project menu > New project for resolution/fps templates.
Import footage, then double-click it or drag it onto the timeline.
Save .frame preserves your editable timeline, graphics and keyframes.
Original footage stays linked on disk rather than embedded in the project.

Media-Licenses and Sources contain media-tool license notices and complete
corresponding source with the build recipe. These files are for reference;
you do not need to compile or install them.

This is an unsigned Windows x64 build, cross-compiled on Linux. Genuine
Windows runtime testing remains outstanding. See README.md for current
editor capabilities and limits.
